# Project overview

**Status: COMPLETED (Sprint 0 foundation)**

ValveTrack is intended to organize and display longitudinal anticoagulation-related information for patients following heart valve surgery. The current application is only an extensible shell; it holds no medical data and provides no user accounts.

## Clinical disclaimer

The system is intended to record, organize, and display clinician- and patient-provided information. It must not independently prescribe, change, or recommend anticoagulant dosage. Any clinical decision remains the responsibility of the treating healthcare professional.

## Current implementation

- Next.js application shell and responsive landing page.
- Engineering and documentation baseline.

## Not implemented

Authentication, authorization, persistence, APIs, clinical records, reports, and notifications.
